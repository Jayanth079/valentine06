# Italian Public (State) Universities — Coded List + English-Taught Programmes

**Scope:** Every Italian *public* (state-funded, "Università Statale") university, listed top-to-bottom, each with a short reference **CODE**, location, and the English-taught **Bachelor's (L / Laurea)** and **Master's (LM / Laurea Magistrale)** programmes.

**⚠️ Read this first — accuracy note:**
- The **list of universities** below is complete and stable.
- **English-taught course lists change every academic year.** Italy has 700+ English programmes. The figures below capture the well-established / representative offering. The **authoritative, always-current** list for any university is:
  - 🇮🇹 **Universitaly** — https://www.universitaly.it (filter: "Corsi in lingua inglese")
  - 🌐 **Study in Italy** — https://studyinitaly.esteri.it
  - Each university's own "Programmes in English" page.
- Always confirm against the official source for the year you intend to enrol (e.g. a.y. 2026/27).

**Legend:** `L` = Bachelor (3 yr) · `LM` = Master (2 yr) · `LM CU` = single-cycle Master (5–6 yr, e.g. Medicine/Law) · 🎓 = degree taught fully in English.

### Special public schools (62–67)
These are elite, mostly **postgraduate & PhD** institutions; teaching is heavily English-medium.

- **62. SNS — Scuola Normale Superiore (Pisa):** undergraduate "ordinary courses" (integrated with UNIPI degrees) + PhD programmes, many in English (Physics, Maths, Neuroscience, Cultural Studies, Political Science & Sociology).
- **63. SSSA — Scuola Superiore Sant'Anna (Pisa):** integrated honours courses + PhD (Biorobotics, Economics, Management, Agricultural Science, Law, Data Science) — strongly English-medium; joint masters with UNITN/UNIPI.
- **64. IMT — Scuola IMT Alti Studi Lucca:** PhD programmes fully in English (Economics, Computer Science, Cognitive & Cultural Systems, Systems Science).
- **65. SISSA (Trieste):** Master's & PhD fully in English (Physics, Mathematics, Neuroscience, Data Science).
- **66. GSSI — Gran Sasso Science Institute (L'Aquila):** PhD fully in English (Physics, Mathematics, Computer Science, Urban Studies & Regional Science).
- **67. IUSS Pavia:** honours courses + PhD (often with SNS/Sant'Anna), English-medium (e.g. Understanding & Managing Extremes, Cognitive Neuroscience).

## C. How to get the *exhaustive, current* course list per university

1. Go to **https://www.universitaly.it** → "Cerca un corso" → filter **Lingua: Inglese** and select the university.
2. Or use **https://studyinitaly.esteri.it** → "Search for a programme" (filter English).
3. Cross-check on the university's own "Study in English / Programmes in English" page.
4. Pay attention to: degree level (L / LM / LM CU), entry tests (e.g. **IMAT** for English-taught Medicine), tuition (income-based, ISEE), and application deadlines (often Dec–Apr for the following September).
